**Prepare your environment before starting Java development.**

## Stage Objective

Prepare the tools and understand the basic concepts needed throughout the Java Backend roadmap.

## Recommended Sequence

### 1. Java Ecosystem

Understand what Java is, what the JVM does, and how Java applications are executed.

**Expected outcome:** Explain the basic relationship between Java source code, bytecode, and the JVM.

### 2. Development Environment

Install and configure:

- JDK.
- IntelliJ IDEA.
- Java environment variables, when required.
- Git.

**Expected outcome:** Create and run a basic Java project from IntelliJ IDEA.

### 3. Git & GitHub

Learn the basic version-control workflow:

- Create and clone repositories.
- Check repository status.
- Stage and commit changes.
- Push and pull changes.
- Understand branches.

**Expected outcome:** Publish a small practice project to GitHub.

### 4. Maven

Understand the role of Maven in Java projects:

- Project structure.
- `pom.xml`.
- Dependencies.
- Maven lifecycle.
- Build commands.

**Expected outcome:** Create and build a simple Maven project.

### 5. Web Fundamentals

Understand the basic communication model behind web applications:

- Client and server.
- HTTP and HTTPS.
- Requests and responses.
- DNS.
- HTTP methods and status codes.

**Expected outcome:** Explain what happens when a client sends an HTTP request to a server.

### 6. JSON & XML

Understand how data is represented and exchanged between applications.

**Expected outcome:** Read simple JSON and XML documents and identify their structure.

### 7. Networking Fundamentals

Build an introductory understanding of IP addresses, ports, protocols, and network communication.

**Expected outcome:** Explain why applications use ports and how clients communicate with servers.

---

## Completion Checklist

- [ ] Understand the Java ecosystem and JVM at a high level.
- [ ] Install and configure the JDK.
- [ ] Install and use IntelliJ IDEA.
- [ ] Perform basic Git operations.
- [ ] Create and build a Maven project.
- [ ] Understand HTTP requests and responses.
- [ ] Read basic JSON and XML.
- [ ] Understand basic networking concepts.

## Before Moving to Beginner

You do not need to become an expert in these topics yet. The goal is to prepare your environment and understand the terminology that will appear throughout the roadmap.
