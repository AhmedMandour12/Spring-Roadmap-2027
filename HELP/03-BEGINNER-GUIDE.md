# Beginner – Stage Guide

**Build a strong foundation in Java and programming.**

## Stage Objective

Develop the ability to write Java programs, understand object-oriented design, use Core Java APIs, solve programming problems, and follow basic software engineering practices.

## Recommended Sequence

### 1. Java Fundamentals

Study the language fundamentals before moving into object-oriented design.

Focus on:

- Variables, data types, and operators.
- Conditions and loops.
- Arrays and strings.
- Methods and parameter passing.
- Packages and access modifiers.
- Basic memory concepts.
- Stack and heap.
- Pass by value.

**Practice:** Build small console programs such as a calculator, number guessing game, and simple data-processing utilities.

### 2. Object-Oriented Programming

Learn how to model application concepts using classes and objects.

Focus on:

- Classes, objects, and constructors.
- Encapsulation.
- Inheritance.
- Polymorphism.
- Abstraction.
- Interfaces and abstract classes.
- Association, aggregation, and composition.

**Practice:** Build a small system using multiple classes and clearly defined responsibilities.

### 3. Core Java

Become comfortable with the APIs and language features used in everyday Java development.

Focus on:

- Exception handling.
- Collections Framework.
- Generics.
- `equals()` and `hashCode()`.
- Comparable and Comparator.
- Enums.
- Lambda expressions.
- Functional interfaces.
- Stream API.
- Optional.
- Date and Time API.
- File handling and Java I/O.

**Practice:** Process collections of objects, filter and sort data, handle errors, and read or write files.

### 4. Data Structures & Algorithms

Study the fundamentals of problem solving.

Focus on:

- Big O notation.
- Arrays and strings.
- Linked lists.
- Stacks and queues.
- Hash tables.
- Searching and sorting.
- Recursion.
- Basic trees.

**Practice:** Solve problems consistently, starting with easy problems and gradually increasing difficulty.

### 5. SOLID Principles

Understand how to design classes that are easier to maintain and extend.

Study all five SOLID principles and implement examples in Java.

### 6. Clean Code

Practice meaningful naming, small focused methods, separation of concerns, and refactoring.

### 7. Unit Testing

Learn the fundamentals of testing, JUnit 5, assertions, and the Arrange–Act–Assert pattern.

---

## Suggested Practical Project

**Library Management System – Console Application**

Implement:

- Book management.
- Member management.
- Borrowing and returning books.
- Searching and filtering.
- Input validation.
- Exception handling.

Use OOP, Collections, and clean code practices. Add basic unit tests where appropriate.

## Completion Checklist

- [ ] Write Java programs independently.
- [ ] Apply the four main OOP principles.
- [ ] Use Collections and Generics.
- [ ] Handle exceptions appropriately.
- [ ] Use Lambda Expressions and Stream API.
- [ ] Understand basic data structures and Big O.
- [ ] Apply SOLID principles in simple examples.
- [ ] Write basic JUnit tests.
- [ ] Complete the practical project.
- [ ] Publish the project on GitHub.

## Before Moving to Intermediate

You should be comfortable writing and organizing Java applications without depending on a tutorial for every step.
