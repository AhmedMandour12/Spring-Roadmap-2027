

#### A. Validation

**Objective:** Learn how to validate incoming requests and ensure that application data meets the required constraints before processing.

| Learning Resources | Notes |
|---|---|
| [Validation in Spring Boot – Hibernate Validator (Crash Course 2021)](https://www.youtube.com/watch?v=0jJsrD6SmUw) | Crash Course |

**Topics to Focus On**

- Introduction to Bean Validation.
- Hibernate Validator.
- @Valid and @Validated.
- @NotNull, @NotBlank, and @NotEmpty.
- @Size and @Min / @Max.
- @Email and @Pattern.
- Field-Level Validation.
- Request Validation.
- Custom Validation Annotations (Introduction).

**Practical Focus**

Implement request validation in a Spring Boot REST API and handle invalid input appropriately.
