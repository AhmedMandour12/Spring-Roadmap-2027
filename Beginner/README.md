## ABOUT THIS LEVEL

Welcome to the Beginner Level!

In this stage, you will build a strong foundation in Java programming and Object-Oriented Programming (OOP), while developing the problem-solving and software engineering skills required for backend development.

The main objectives of this level are to:

- Master Java programming fundamentals.
- Understand and apply Object-Oriented Programming concepts.
- Become familiar with Core Java and its essential APIs.
- Develop problem-solving skills through coding practice.
- Understand fundamental software design principles.
- Write clean, readable, and maintainable code.
- Get introduced to unit testing and code quality.

> **Learning Approach:** Focus on understanding concepts and applying them through coding exercises and practical projects rather than simply watching courses.

### 08 — Practical Application

**Objective:** Apply what you have learned by building a complete console-based Java application.

**Suggested Project: Library Management System**

**Functional Requirements**

- Add, update, delete, and view books.
- Manage library members.
- Borrow and return books.
- Search for books by title or author.
- Track book availability.
- Validate user input.
- Handle application errors properly.

**Technical Requirements**

- Apply Object-Oriented Programming principles.
- Use Collections to manage application data.
- Follow SOLID principles where appropriate.
- Organize the code into meaningful classes.
- Apply clean code practices.
- Write basic unit tests.

> **Goal:** Build the project yourself without copying a complete solution. The purpose is to demonstrate your understanding of Java and OOP through practical implementation.

## COMPLETION CHECKLIST

Before moving to the next level, make sure you can:

### Java Fundamentals
- [ ] Write Java programs using fundamental language features.
- [ ] Understand variables, data types, loops, and methods.
- [ ] Explain basic memory management and Pass by Value.

### Object-Oriented Programming
- [ ] Understand and apply the four OOP principles.
- [ ] Design classes and create objects.
- [ ] Understand inheritance, polymorphism, and abstraction.
- [ ] Distinguish between interfaces and abstract classes.
- [ ] Understand object relationships.

### Core Java
- [ ] Work with Java Collections.
- [ ] Understand Generics and Exception Handling.
- [ ] Use Lambda Expressions and Functional Interfaces.
- [ ] Process data using the Stream API.
- [ ] Understand equals() and hashCode().

### Software Engineering
- [ ] Understand and apply SOLID principles.
- [ ] Follow basic Clean Code practices.
- [ ] Understand the fundamentals of Unit Testing.
- [ ] Write basic tests using JUnit.

### Practical Experience
- [ ] Complete the suggested practical project.
- [ ] Upload your project to GitHub.
- [ ] Be able to explain your code and design decisions.
